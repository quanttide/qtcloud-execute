# 工作台

## 页面布局

左边是清单，右边是任务看板。

任务看板按照状态划分，包括未开始、执行中、评审中、已完成的模型。

## 清单

用于隔离一类事情。量潮科技有量潮数据、量潮课堂、量潮云三个主营业务，因此分为以上三个清单，再加上一个默认清单。

## 任务

标题：按照动名词写，比如“升级量潮执行云客户端”。

描述：准确的阐述需要做什么、如何验收等。

优先级：
- 紧急：停下所有事情处理这个。
- 高：优先处理。
- 中：默认情况。
- 低：不一定要做，先放着。

状态：
- 未开始：还没有开始做
- 执行中：负责人正在处理
- 评审中：复核人正在验收
- 已完成：已经做完。
