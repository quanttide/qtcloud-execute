# TaskList 模型设计（清单——业务级实体）

## 定位

一个业务的清单——**实体**（一个业务一个清单），与档案结构同构（业务文件夹 → 职能文件）。

## 定义

```
TaskList（清单）= 一个业务（qtdata / qtclass / qtcloud）——实体
└── Group（分组）= 一个职能（business / product / operation）——清单内组织单元

Task（任务）属于 清单 × 分组
```

## 结构示例

```
qtcloud 清单（业务）
├── product 分组：财务平台部署、议事管理迭代…
qtclass 清单
├── operation 分组：实训基地招聘运营…
└── product 分组：课堂创新…
```

## 关键规则

1. **一个业务一个清单**：清单 = 业务（实体，可持久化）
2. **职能即分组**：Group = 职能（business/product/operation）——清单内组织单元
3. **任务唯一归属**：一个 Task 属于 一个清单 × 一个分组
4. **与档案同构**：清单结构 = profile 结构（业务文件夹 × 职能文件）——工具与档案认知一致

## 序列化

- TaskList（业务清单）：持久化（清单元数据 + 分组定义）
- Task：按清单归属存储

## 测试

- 清单/分组归属正确（Task 落在 业务×职能）
- 分组切换/重命名不丢任务

## 验收

- 一个业务一个清单，职能分组清晰
- 任务归属唯一（清单 × 分组）
- 与 profile 档案结构一致（业务 × 职能）
