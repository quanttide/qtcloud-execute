# TaskList 模型设计（清单——视图不是实体）

## 定位

一组任务的容器——**视图不是独立实体**（事件风暴约束 1）：只通过 Task 操作，清单本身不存数据。

## 定义

```
TaskList（视图）
├── 分组维度：业务（qtdata / qtclass / qtcloud）
├── 视图维度：日期流（今天/本周）/ 状态档案（进行中/阻塞）
└── 操作：全部委托给 Task（增删/重排/过滤是视图行为）
```

## 关键规则

1. **清单是视图不是实体**：不持久化清单本身——清单 = 查询条件（业务 × 维度）
2. **分组即业务**：业务是清单的第一分组维度（qtdata/qtclass/qtcloud）
3. **任务唯一归属**：一个 Task 属于一个业务（不跨清单）

## 视图示例

```
按业务（qtcloud）
└── 按状态（进行中）
    ├── 财务平台部署（紧急）
    └── 议事管理迭代（高）

按日期流（今日日志）
└── 今天新增/更新任务的流水
```

## 序列化

- 清单不序列化（无独立数据）——Task 序列化即可
- 分组/过滤在查询层完成

## 测试

- 查询层：按业务 × 状态过滤正确
- 清单切换：不改变 Task 数据（视图无副作用）

## 验收

- 清单切换无数据副作用
- 分组/过滤与 Task 数据一致
