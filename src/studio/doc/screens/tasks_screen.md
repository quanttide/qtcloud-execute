# 清单页（TasksScreen）设计

> 对应：doc/models/task_list.md（清单=业务，分组=职能）

## 定位

执行云首页——**业务清单视图**：一个业务一个清单，职能为组内分组，展示任务。

## 功能区

```
┌────────────────────────────────┐
│ 清单切换（顶部）：qtdata ▾      │  ← 业务清单（qtdata/qtclass/qtcloud）
├────────────────────────────────┤
│ 分组：product（职能分组头）       │
│  ├── 财务平台部署     🔴紧急 进行中 │
│  ├── 议事管理迭代     🟠高   评审中 │
│  └── 文档中心上线     🟢中   已完成 │
│ 分组：operation                  │
│  └── 实训基地招聘运营   🔴紧急 进行中 │
│ （空分组折叠/显示"暂无任务"）       │
└────────────────────────────────┘
```

## 交互行为

### 清单切换

- 顶部清单选择器（qtdata/qtclass/qtcloud）——切换业务清单
- 切换不丢数据（视图行为）

### 分组展示

- 职能分组（business/product/operation）为组头，组内任务列表
- 空分组：折叠或显示"暂无任务"
- 分组可折叠（收起/展开）

### 任务列表

- 每条任务：title + priority 色点 + status 徽标
- 点击任务 → 跳转任务详情页（/tasks/:id）
- 排序：默认按 priority（紧急→高→中→低）组内排序

## 数据

| 项 | 说明 |
|----|------|
| 清单 | TaskList（业务）——loadTasks 注入 |
| 分组 | 职能 Group（business/product/operation） |
| 任务 | Task 列表（title/status/priority） |

## 测试（screens/tasks_screen_test.dart）

- 清单加载渲染（注入假数据源）
- 分组显示正确（业务 × 职能）
- 空分组提示/折叠
- 点击任务跳转详情
- 清单切换无副作用

## 验收

- 一个业务一个清单，职能分组清晰
- 任务按优先级组内排序
- 清单切换不丢数据
