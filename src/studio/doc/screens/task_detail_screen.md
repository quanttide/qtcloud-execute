# 任务详情页（TaskDetailScreen）设计

> 对应：doc/models/task.md（title/description/status/priority）

## 定位

单个任务的完整视图——查看/编辑四字段，推进状态。

## 功能区

```
┌────────────────────────────────┐
│ 返回 ← 财务平台部署               │
├────────────────────────────────┤
│ 状态（可切换）                    │
│  ○ 未开始  ● 进行中  ○ 评审中  ○ 已完成 │
│ 优先级（可调整）                  │
│  ● 紧急   ○ 高   ○ 中   ○ 低     │
├────────────────────────────────┤
│ 描述（可编辑）                    │
│  ACR 实例凭证待确认，已发 issue…  │
└────────────────────────────────┘
```

## 交互行为

### 状态流转

- 四态切换：未开始 → 进行中 → 评审中 → 已完成（**只前进**）
- 已完成状态：任务进入归档视图（列表隐藏/归档分组）

### 优先级调整

- 四档单选（紧急/高/中/低）
- AI 建议：显示推荐优先级（AI 建议 + 用户确认）——点击应用

### 描述编辑

- description 可编辑（展开细节）
- 保存即持久化（仓储 update）

## 数据

| 项 | 说明 |
|----|------|
| 任务 | Task（id 加载——loadTasks 注入） |
| 状态 | TaskStatus（只前进） |
| 优先级 | TaskPriority（AI 建议 + 人确认） |

## 测试（screens/task_detail_screen_test.dart）

- 四字段渲染（title/description/status/priority）
- 状态前进合法（非法回退拒绝/隐藏）
- 优先级选择 + AI 建议应用
- 描述编辑保存
- 已完成 → 归档联动

## 验收

- 任务四字段完整可操作
- 状态只前进
- 优先级 AI 建议 + 人确认
