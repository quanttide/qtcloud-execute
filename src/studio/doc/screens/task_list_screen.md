# 清单页（TaskListScreen）设计

> 对应：doc/models/task_list.md（清单=业务，分组=职能）

## 定位

执行云首页——**业务清单的二维看板**：列=分组（职能，结构维度），行=状态（推进阶梯，时间维度）。

## 功能区

```
┌──────────────────────────────────────────┐
│ 清单切换器（顶部）：qtdata  qtclass  qtcloud  ▸ 新增 │  ← 数据驱动，不静态假设
├────────────┬──────────┬──────────┬─────────┤
│            │ product  │ operation│ business│  ← 列 = 分组（职能）
├────────────┼──────────┼──────────┼─────────┤
│ 未开始       │ [财务平台] │ [实训招聘] │          │  ← 行 = 状态
├────────────┼──────────┼──────────┼─────────┤
│ 进行中       │ [议事管理] │ [运营时间] │          │
├────────────┼──────────┼──────────┼─────────┤
│ 评审中       │ [文档中心] │          │          │
├────────────┼──────────┼──────────┼─────────┤
│ 已完成       │ [工具库]  │          │          │
└────────────┴──────────┴──────────┴─────────┘
  卡片 = title + priority 色点，行内按优先级排序
```

## 交互行为

### 清单切换器（顶部）

- 清单列表**从数据加载**（不硬编码业务）——新增业务 = 新增清单，切换器自动跟随
- 形态：移动端顶部滑动条/抽屉，桌面左侧清单列表——不锁定
- 支持新增/重命名清单

### 二维看板

- **列 = 分组**（职能：product/operation/business）——结构维度，横向展开（与档案同构）
- **行 = 状态**（未开始→进行中→评审中→已完成）——推进阶梯，纵向滚动
- 行内排序：按 priority（紧急→高→中→低）
- 空单元格：显示"暂无任务"占位（不空白）
- 行头可折叠（如"已完成"行默认折叠——减少噪声）

### 任务卡片

- 卡片：title + priority 色点
- 点击卡片 → **弹窗打开详情**（TaskDetailDialog——就地操作，不跳页）
- 状态推进：弹窗内切换（移动端拖拽不便，弹窗兜底；桌面可拖拽跨行）

## 数据

| 项 | 说明 |
|----|------|
| 清单 | TaskList 列表（动态加载） |
| 列 | 分组 Group（职能） |
| 行 | 状态 TaskStatus（四态） |
| 卡片 | Task（title/priority/status） |

## 测试（screens/task_list_screen_test.dart）

- 清单切换器动态加载（新增清单自动出现）
- 二维布局正确（分组 × 状态交叉定位）
- 行内优先级排序
- 空单元格占位
- 点击卡片弹窗打开
- 清单切换无副作用

## 验收

- 列=分组、行=状态（与档案结构同构）
- 清单数据驱动（不静态假设）
- 卡片点击弹窗，操作即存
