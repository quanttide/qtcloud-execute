# 二维看板组件（BoardView）设计

> 对应：doc/screens/task_list_screen.md（列=分组 × 行=状态）
> 依赖：BoardCubit（tasks → 投影矩阵）

## 定位

执行云核心视图——二维看板：**列 = 分组（职能，结构横向）**，**行 = 状态（推进阶梯，纵向）**。

## 组件结构

```
BoardView
├── GroupHeader × N（列头——分组名，横向排）
├── StatusRow × 4（行——未开始/进行中/评审中/已完成）
│   ├── 行头：状态名 + 折叠箭头（"已完成"默认折叠）
│   └── 单元格 × N（与列头交叉）
│       ├── TaskCard（任务卡片——点击弹窗/桌面拖拽）
│       └── EmptyCell（空占位——"暂无任务"）
```

## 布局规则

| 元素 | 规则 |
|------|------|
| 列 = 分组 | 来自清单的职能分组（product/operation/business）——结构维度 |
| 行 = 状态 | 四态固定顺序（未开始→进行中→评审中→已完成）——推进阶梯 |
| 行列交叉 | 单元格 = 分组 × 状态 的任务集合 |
| 行内排序 | 按 priority（紧急→高→中→低） |
| 空单元格 | EmptyCell 占位（不空白） |
| 行折叠 | 行头可折叠（"已完成"默认折叠——减少噪声） |

## 交互行为

- 行头点击 → 折叠/展开
- 单元格：TaskCard 点击 → 弹窗；桌面拖拽跨行（状态推进）
- 看板整体：列固定，纵向滚动（移动端自然）

## 数据

| 项 | 说明 |
|----|------|
| 来源 | BoardCubit（tasks——投影为 分组×状态 矩阵） |
| 投影 | Bloc 层完成——页面只渲染矩阵 |
| 操作 | 卡片点击/拖拽 → 回调（BoardCubit.updateTask） |

## 测试（widgets/board_view_test.dart）

- 矩阵投影正确（分组 × 状态 交叉定位）
- 行内优先级排序
- 空单元格占位
- 行折叠/展开
- 卡片点击/拖拽回调

## 验收

- 列=分组、行=状态（与档案结构同构）
- 投影在 Bloc 层，页面纯渲染
- 空单元格有占位、已完成行可折叠
