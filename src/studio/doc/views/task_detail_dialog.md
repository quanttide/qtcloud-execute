# 任务详情组件（TaskDetailDialog）设计

> 对应：doc/models/task.md（title/description/status/priority）
> 形态：**弹窗组件**——清单页点击任务打开，非独立页面

## 定位

单个任务的完整视图——弹窗形式（ModalBottomSheet/Dialog），在清单内就地操作，不跳页。

## 组件结构

```
┌────────────────────────────────┐
│ 财务平台部署             [关闭 ×] │  ← 任务 title
├────────────────────────────────┤
│ 状态（四态横排可点）               │
│  ○ 未开始  ● 进行中  ○ 评审中  ○ 已完成 │
│ 优先级（四档横排可点）             │
│  ● 紧急   ○ 高   ○ 中   ○ 低     │
├────────────────────────────────┤
│ 描述（可编辑）                    │
│  ACR 实例凭证待确认，已发 issue…  │
│  [保存]                          │
└────────────────────────────────┘
```

## 交互行为

### 打开

- 清单页点击任务 → 弹窗打开（携带 Task 数据）
- 弹窗内操作即改即存（仓储 update）

### 状态流转

- 四态切换：未开始 → 进行中 → 评审中 → 已完成（只前进）
- 已完成：关窗后列表归档联动

### 优先级调整

- 四档单选（紧急/高/中/低）
- AI 建议：弹窗内显示推荐优先级（AI 建议 + 用户确认）

### 描述编辑

- description 可编辑 + 保存（仓储 update）

## 数据

| 项 | 说明 |
|----|------|
| 入参 | Task（清单页传入） |
| 操作 | status/priority/description 变更 → 仓储 update |
| 回调 | onUpdated（清单页刷新列表） |

## 测试（widgets/task_detail_dialog_test.dart）

- 弹窗打开渲染四字段
- 状态前进合法（非法回退拒绝）
- 优先级选择 + AI 建议应用
- 描述编辑保存（回调触发）
- 关闭不丢未保存修改（或提示）

## 验收

- 清单内点击任务弹窗打开（不跳页）
- 四字段完整可操作
- 修改即保存，清单页同步刷新
