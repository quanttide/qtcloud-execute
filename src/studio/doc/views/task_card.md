# 任务卡片组件（TaskCard）设计

> 对应：doc/screens/task_list_screen.md（二维看板单元格内容）
> 形态：看板内的最小展示单元——点击打开详情弹窗

## 定位

二维看板（分组 × 状态）单元格中的任务卡片——紧凑展示，一眼可辨优先级。

## 组件结构

```
┌────────────────┐
│ 🔴 财务平台部署   │  ← title + priority 色点（紧急红/高橙/中蓝/低灰）
│ ACR 凭证待确认…  │  ← description 摘要（1 行省略，可选）
└────────────────┘
```

## 展示规则

| 元素 | 规则 |
|------|------|
| title | 必显，2 行截断 |
| priority 色点 | 四档色（紧急🔴/高🟠/中🔵/低⚪）——行内排序依据 |
| description | 有则显示 1 行摘要（可选——单元格小，可隐藏） |
| status | **不显示**（状态已由所在行表达——不重复） |

## 交互行为

- 点击 → 打开 TaskDetailDialog（弹窗——传入 Task + onUpdated 回调）
- 桌面端可拖拽跨行（状态推进）——拖拽视觉：抬起阴影 + 落点高亮
- 无长按/滑动等隐藏操作（简单优先）

## 数据

| 项 | 说明 |
|----|------|
| 入参 | Task（title/description/priority/status） |
| 状态 | 由所在行列表达（卡片不重复） |
| 回调 | onTap → 弹窗；onDragEnd → 状态变更 |

## 测试（widgets/task_card_test.dart）

- title + priority 色点渲染（四档色正确）
- 点击触发回调（弹窗打开）
- description 摘要截断
- 拖拽跨行 → 状态变更回调（桌面）

## 验收

- 卡片一眼可辨优先级
- 状态不重复显示（行已表达）
- 点击弹窗、拖拽推进（桌面）
